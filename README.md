# Dra. Eliane Cardoso, cirurgiã-dentista

Site de uma página do consultório da Dra. Eliane Cardoso, na Rua Professor Annes Dias, 154, Centro Histórico, Porto Alegre.

Arquivo único (`index.html`), sem build. Publicar na Vercel com Framework Preset "Other", sem build command e sem output directory.

Pendências antes de tirar o `noindex`:
- número do CRO-RS (obrigatório pela Resolução CFO 196/2019);
- fotos da doutora e do consultório;
- tratamentos que ela quer destacar;
- convênios (se houver), sala/conjunto e Instagram.
